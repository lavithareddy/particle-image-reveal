# Particle Image Reveal ✨

A Python-based particle animation that transforms thousands of moving particles into an image.

## Features

- 🎨 Particle image reveal
- 🌈 Color particle rendering
- 🖼️ Image-to-particle conversion
- 🎵 Background music support
- ⚡ Smooth particle animation
- 🐍 Built with Python & Pygame

## Project Structure

```
particle-image-reveal/
│── assets/
│   ├── tirumala.png
│   └── bg.mp3
│
├── main.py
├── particle.py
├── image_loader.py
├── config.py
├── requirements.txt
```

## Installation

Clone the repository:

```bash
git clone https://github.com/lavithareddy/particle-image-reveal.git
```

Go to the project folder:

```bash
cd particle-image-reveal
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py
```
